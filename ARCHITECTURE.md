## 数据流向

### 扫码充电流程

```
用户小程序 → Gateway → charging-service → Redis(锁)
                                    ↓
                              charging_pile(状态更新)
                                    ↓
                              charging_order(创建订单)
                                    ↓
                              实时记录 (charging_record)
                                    ↓
                              停止充电 → 计算费用
                                    ↓
                              order-service(订单完成)
                                    ↓
                              payment-service(扣款)
                                    ↓
                              user_balance(余额更新)
                                    ↓
                              message-service(通知)
```

### 支付流程

```
用户 → Gateway → payment-service
                    ↓
            ┌───────┴───────┐
            ↓               ↓
      微信支付          支付宝支付
            ↓               ↓
            └───────┬───────┘
                    ↓
            payment_transaction
                    ↓
        ┌───────────┴───────────┐
        ↓                       ↓
  order-service           user-balance
  (订单状态)              (余额充值)
        ↓                       ↓
  message-service(发送通知)
```

## 技术栈分层

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Vue 3 + Element Plus | 管理后台 |
| 移动端 | 微信小程序 | 用户端 |
| 网关 | Spring Cloud Gateway | 统一入口 |
| 微服务 | Spring Boot 3.2 | 业务服务 |
| 注册中心 | Nacos 2.2 | 服务发现 |
| 配置中心 | Nacos Config | 配置管理 |
| 数据库 | MySQL 8.0 | 数据存储 |
| 缓存 | Redis 7.x | 高速缓存 |
| ORM | MyBatis-Plus 3.5 | 数据访问 |
| 限流 | Sentinel 1.8 | 流量防护 |
| 监控 | Prometheus | 指标采集 |
| 可视化 | Grafana | 仪表盘 |
